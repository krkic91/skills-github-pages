## Role-Play

### Scenario: A manager and an employee discussing a problem with a project deadline.

**Manager:** We've encountered a delay in the project. What do you think caused this issue?

**Employee:** I believe the delay is due to unforeseen technical difficulties. The software we were using crashed unexpectedly, and it took us a while to get it back up and running.

**Manager:** I see. Were there any other factors that contributed to the delay?

**Employee:** Yes, there were also some issues with the supplier. They delivered the materials late, which set us back a few days.

**Manager:** That's concerning. Have we addressed these issues with the supplier?

**Employee:** We have. I've already contacted them, and they've assured us that future deliveries will be on time.

**Manager:** Good to hear. What steps have we taken to mitigate the technical difficulties?

**Employee:** We've updated the software and implemented a backup system to prevent future crashes. Additionally, we've scheduled regular maintenance checks.

**Manager:** Excellent. Let's ensure we keep a close eye on these areas moving forward. Is there anything else we need to consider?

**Employee:** We might need to allocate more resources to the project to make up for lost time. Perhaps we can bring in additional team members.

**Manager:** That's a good idea. I'll look into reallocating some resources. Let's also set up a meeting with the team to discuss these changes and ensure everyone is on the same page.

**Employee:** Agreed. I'll prepare a report on the current status and the steps we've taken so far.

**Manager:** Thank you. Let's aim to get back on track as soon as possible. Keep me updated on any further developments.

<!-- Source: F2_M01_L18.pdf, page 3 -->

### Role-play Analysis

1. What are the two main issues causing the project delay?

2. What steps does the employee take to prevent future technical difficulties?

3. What solution does the employee suggest to make up for lost time?

4. How does the employee plan to keep the manager informed about the project's progress?

5. How effective do you think the communication between the manager and the employee is in this dialogue?

### Discussion

1. How do you deal with problems at the workplace?

2. What do you consider to make sure that problems will be addressed in your workplace?

## Production

**ACTIVITY 1:** Create a script based on this scenario to be acted once done. Don’t forget to use the key vocabulary phrases when necessary.

1. Scenario: Client Reporting a Problem with a Software Product

### 2. Characters

- Client (Alex): A user experiencing issues with a software product.

- Service Provider (Jamie): A customer support representative from the software company.

### Sample

**Alex:** Hi, I’m having trouble logging in. It says my password is incorrect.

**Jamie:** The main challenge is the password reset issue. Let’s work on a fix together. Can you check your spam folder for the reset email?

**Alex:** I checked, but it’s not there.

**Jamie:** The root cause seems to be a server delay. A possible solution could be to reset it manually. Can you confirm your email?

**Alex:** It’s alex.nguyen@example.com.

**Jamie:** I’ve just sent the reset link. Please try it again.

**Alex:** It worked! Thank you.

**Jamie:** We need to find a way to prevent this from happening again. I recommend updating your password now.

1. What problem is being discussed?

2. How does the service provider propose to solve the problem?
