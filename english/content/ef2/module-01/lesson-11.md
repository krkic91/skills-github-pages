## Warm-Up

Task Delegation Discussion

- Have you ever had to delegate a task? How did you do it?

**Workplace Task Example:** fixing a bug, updating software, writing a report

- Tell which task(s) you would delegate and to whom.

## Role-Play

### Scenario: Emma, a project manager, is delegating a task to Tom, a software developer.

Later, Tom provides an update on his progress.

**Emma:** Hi Tom, could you take care of testing the new feature before Friday?

**Tom:** Sure, I can do that. Do you need a detailed report on the test results?

**Emma:** Yes, please. Make sure to check for any security issues and report any bugs.

**Tom:** Got it. I’ll start today and keep you updated. (Later in the week…)

**Emma:** Hi Tom, how is the testing going?

**Tom:** I’ve completed most of the tests, but I found a security issue that needs to be fixed. It might take an extra day to resolve.

**Emma:** Thanks for the update. Let me know when it’s fixed.

**Tom:** Will do!

<!-- Source: F2_M01_L11.pdf, page 2 -->

### Role-play Analysis

1. What task did Emma delegate to Tom?

2. What instructions did Emma give about the task?

3. How did Tom update Emma about the task’s progress?

4. What issue did Tom find during testing?

5. How did Emma respond to the update?

### Discussion

- What challenges do you face when delegating or reporting on tasks in English?

## Production

Speaking Practice for Updating and Delegating Tasks

1. Work in pairs (Manager & Employee).

2. Switch roles after each round.

**Scenario 1:** Delegating a Task

**Manager:** Assign a report-writing task to your team member. Include details (deadline, key points to cover, format).

**Employee:** Ask for clarification if needed and confirm understanding.

**Scenario 2:** Providing a Task Update

**Employee:** You are working on a project and your manager asks for an update. Report your progress, any issues, and estimated completion time.

**Manager:** Ask follow-up questions and provide feedback.

## Key Vocabulary

| Word/Phrase | Use | Example |
| --- | --- | --- |
| Delegate | To assign a task to<br>someone else | I will delegate the report-<br>writing task to Sarah. |
| Deadline | The final date by which a<br>task must be completed | The deadline for the project<br>is next Friday. |
| On track | Moving forward as planned<br>or expected | The project is on track for<br>completion next week. |
| Could you take care<br>of…? | Requesting someone to do<br>a task | Could you take care of the<br>client emails today? |
| This task needs to be<br>done by… | Used to set a deadline | This task needs to be done<br>by next Wednesday. |
