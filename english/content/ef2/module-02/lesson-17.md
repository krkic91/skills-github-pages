## Vocabulary: Direct vs. Indirect Requests

1. Softening Language – used to reduce directness of a message, making it less confrontational or aggressive.

### Examples

- Direct Request – I need the report by Friday.

- Indirect / Softened – I was wondering if it would be possible to get the report by Friday?

- Direct Request – You need to provide feedback on this report.

- Indirect / Softened – I’d appreciate it if you could provide feedback on this report.

2. Formal Phrasing – the use of polite, professional, and objective language in written or spoken communication, particularly in formal or business settings.

### Examples

- Direct Request – Can you help me?

- Indirect / Formal – I would appreciate it if you could assist me with this matter.

- Direct Request – Can you submit the latest sales figures?

- Indirect / Formal – Could you please provide me with the latest sales figures?
